# 大纲模板库

输出正文时必须使用以下任一模板的章节结构。所有模板共用统一骨架：

```
# <标题>
## 摘要
## 大纲
## 正文
## 参考来源
```

`正文` 的二级标题按模板展开。

## 模板 A：科普 / 介绍文
适用：概念介绍、产品说明、科普。

```
## 正文
### 是什么
### 为什么重要
### 核心要点（1–3 条）
### 常见误区
### 小结
```

## 模板 B：分析 / 报告
适用：调研、分析、复盘。

```
## 正文
### 背景
### 现状
### 关键发现（逐条，附数据来源）
### 结论与建议
```

## 模板 C：教程 / 操作指南
适用：how-to、上手教程。

```
## 正文
### 前提条件
### 操作步骤（编号）
### 常见问题
### 延伸阅读
```

## 选择规则
- 话题偏「讲解概念」→ 模板 A
- 话题偏「判断、评估」→ 模板 B
- 话题偏「怎么做」→ 模板 C
- 无明显倾向 → 模板 A
