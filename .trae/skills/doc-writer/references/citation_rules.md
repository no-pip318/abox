# 引用规范

## 何时标来源
- 引用用户提供的参考材料：全部标注
- 引用外部数据、结论、原文：标注
- 通用常识：无需标注

## 标注格式
正文内用方括号编号，与末尾「参考来源」一一对应：

```
研究表明，X 可以降低 30% 的能耗 [1]。

## 参考来源
[1] 作者/机构. 《标题》. 年份.
```

## 用户素材的标注
仅使用用户提供的材料时，来源写：

```
[1] 用户提供的参考材料：《材料名称》
```

## 禁止事项
- 不得编造作者、链接、年份
- 不得为无法溯源的结论添加虚假引用
- 同一来源多处引用复用同一编号
- 无任何来源时，「参考来源」写「无（未使用外部材料）」
